# ComplySense — Phase 4 & 5 Technical Implementation Plan

This plan details the implementation of **Phase 4 (Super Admin Portal)** and **Phase 5 (Institution Admin Portal)**. It includes backend REST endpoints (FastAPI + SQL queries) and frontend components/pages (React + Zustand + Recharts).

---

## User Review Required

> [!IMPORTANT]
> **API Implementation Strategy:**
> To ensure reliability and quick validation, all database queries will be executed asynchronously using SQLAlchemy's raw SQL interface (`session.execute(text(...))`). This mirrors the established pattern in `UserRepository` and avoids complex ORM setup.
> If any environment variables or external databases (MongoDB/Supabase) are missing or misconfigured locally, standard fallback mock behaviors are embedded in the service layer to prevent crashes.

## Proposed Changes

### 1. Backend API Routing

We will implement complete REST endpoints inside the existing stub routers under `backend/app/routers/`.

#### [MODIFY] [institutions.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/institutions.py)
* `GET /api/v1/institutions/stats` — Returns platform-wide statistics (Total Institutions, Active Users, Incidents, Average Compliance Score).
* `GET /api/v1/institutions/anomaly-alerts` — Polls AI anomaly logs (returns mock logs if no anomalies detected).
* `GET /api/v1/institutions` — List all registered institutions with state, status, type, and search queries.
* `POST /api/v1/institutions` — Create a new institution.
* `GET /api/v1/institutions/{id}` — Fetch details for a specific institution (with user count, department count, and compliance %).
* `PUT /api/v1/institutions/{id}/status` — Toggle an institution's `is_active` status.
* `PATCH /api/v1/institutions/{id}` — Edit an institution's details.

#### [MODIFY] [audit.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/audit.py)
* `GET /api/v1/audit/logs` — Fetch all logs across institutions (for Super Admin) or scoped to the user's institution. Supports pagination, user search, date filters, and CSV format download (`GET /api/v1/audit/logs?format=csv`).
* `GET /api/v1/audit/recent` — Fetch the last 10 audit logs.

#### [MODIFY] [rbac.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/rbac.py)
* `GET /api/v1/rbac/matrix` — Generates a permissions matrix mapping every `PermissionKey` to each of the 9 roles for horizontal rendering.

#### [MODIFY] [users.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/users.py)
* `GET /api/v1/users` — List all users in the institution (scopes to active institution).
* `POST /api/v1/users` — Register a new user with default/random password and triggers setup email simulation.
* `PATCH /api/v1/users/{id}` — Update user profile details.
* `PUT /api/v1/users/{id}/status` — Toggle `is_active` for a user.
* `POST /api/v1/users/{id}/reset-password` — Generate reset token and return simulation payload.

#### [MODIFY] [departments.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/departments.py)
* `GET /api/v1/departments` — List departments.
* `POST /api/v1/departments` — Add a new department.
* `PATCH /api/v1/departments/{id}` — Edit department info or assign reviewer user ID.

#### [MODIFY] [calendar.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/calendar.py)
* `GET /api/v1/calendar` — Fetch compliance calendar items.
* `POST /api/v1/calendar` — Add a new calendar event.

#### [MODIFY] [policies.py](file:///c:/Users/hp/Desktop/complysense-clean/backend/app/routers/policies.py)
* `GET /api/v1/policies/reports` — Fetch list of generated compliance reports.
* `POST /api/v1/policies/reports/generate` — Mock trigger AI compliance report generation.

- Run TypeScript typecheck to verify there are no compilation errors:
  ```bash
  cmd /c "npm run typecheck"
  ```
- Run Vite production compilation:
  ```bash
  cmd /c "npm run build"
  ```

### Manual Verification
- Log in as Super Admin (`superadmin@complysense.com`) and test:
  * Platform Dashboard stats and charts loading.
  * Adding a new institution and toggling its active status.
  * Filtering the global audit trail and triggering CSV export.
  * Navigating the horizontal Roles and Permissions matrix.
- Log in as Institution Admin (`admin@complysense.com`) and test:
  * Overall Compliance score cards and department heatmap rendering.
  * Adding/editing departments and assigning department reviewers.
  * Adding/editing users, toggling activation status, and triggering password reset.
  * Toggling calendar Month/List views and adding events.
  * Triggering reports generation.
